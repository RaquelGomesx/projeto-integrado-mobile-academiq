# AcademiQ
App mobile de gestão de tarefas acadêmicas com notificações inteligentes, planejamento de estudos e integração ao calendário.

## Como rodar
1. Instale o Flutter SDK
2. `git clone https://github.com/<usuario>/projeto-integrado-mobile-academiq.git`
3. `cd projeto-integrado-mobile-academiq/src`
4. `flutter pub get`
5. `flutter run`
